# QR Code

Generate QR codes from any text or URL. Custom colors, multiple sizes, download as PNG.

**Category:** Utilities  
**Live:** [qrcode.freeappstore.online](https://qrcode.freeappstore.online)

## Development

```bash
pnpm install
pnpm dev
```

## Deploy

Push to main — auto-deploys to R2 via GitHub Actions.
